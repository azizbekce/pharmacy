# Pharmacy Management System

Pharmacy Management System is a web application for managing medicines, inventory, users, and sales.

## Project history

- Created in 2024
- Modernized and improved in 2026

## Features

- User registration and secure login
- Medicine inventory management
- Stock quantity validation
- Atomic medicine sales
- Low-stock dashboard alerts
- Uzbek, Russian, and English interface
- Light and dark themes
- Device theme synchronization
- Responsive desktop and mobile layout

## Local setup

1. Copy the project into `C:\xampp\htdocs\Pharmacy`.
2. Create a MySQL database named `pharmacy`.
3. Import `pharmacy.sql` using phpMyAdmin.
4. Start Apache and MySQL in XAMPP.
5. Open `http://localhost/Pharmacy/`.
